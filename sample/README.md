# VoiceAnalyzer 수동 테스트 자료

`data/<인물 이름>/`은 워커가 사용하는 등록 참조 음성입니다. `sample/<인물 이름>/`은 해당 인물이 있다고 지정한 수동 테스트 입력, `sample/<인물 이름> 아님/`은 그 인물이 없다고 지정한 대조 입력입니다. 워커는 `sample/`을 자동 등록하거나 분석하지 않습니다. 실제 화자가 누구인지 확정되지 않은 대조 입력에 다른 사람의 이름을 붙이지 않습니다.

`manifest.csv`와 각 샘플 폴더의 `URL_목록.csv`에는 원본 URL, 정답 상태, 파일 경로, SHA-256, 평가 길이가 있습니다. CSV는 UTF-8 BOM입니다. `expected=absent`는 그 인물이 **없는지 시험하는 입력**이라는 뜻입니다. `unverified_speaker_mix`는 여러 화자가 있어 대상의 정확한 발화 구간을 독립 확인하지 못했다는 뜻입니다. 라벨이 없는 화자를 모델 결과만으로 확정하지 않습니다.

원본 영상 또는 재인코딩 없이 복사한 음성 트랙만 보관하며 16 kHz PCM이나 모델 입력용 잘라내기 파일은 넣지 않았습니다. 기존 大西亜玖璃 부재 대조군 중 seigura와 CUTIE_STREET_는 발화가 있는 M4A이며, CUTIE_STREET_는 이전 Anime VA 임계값 0.38에서 309~312초의 오검출을 재현한 자료입니다. sagarafff는 오디오 트랙은 있지만 VAD 발화가 없는 M4A입니다. mygirl_official과 cocona_nonaka는 음성 트랙이 없는 원본 MP4라 화자 판별의 성공 음성 표본으로 세지 않습니다. 2026-11-06에 추가한 부재 게시물 8개의 AAC 트랙은 Chrome이 확인한 최고 128 kbps HLS 오디오를 복사했습니다. ariablue_와 crocodile_staff는 같은 미디어 ID를 가리키므로 두 파일 이름은 하드 링크이며 공간은 한 번만 사용합니다. 운영 브로커가 선택한 MP4의 오디오와 HLS 오디오의 판정 점수가 다를 수 있어, 원본 출처는 CSV와 실험 결과에 구분해 기록합니다. Nijigaku_movie 영상은 원본 MP4와 재인코딩하지 않은 HLS 오디오 M4A를 함께 보관합니다. 두 파일은 같은 게시물의 서로 다른 미디어 표현입니다. 결과 JSON과 재현 스크립트는 `work/experiments/`에 따로 있습니다.
